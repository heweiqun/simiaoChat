# 四喵对话生成器 · 可编辑版

独立的 React + TypeScript + Vite 项目。旧版仓库根目录及静态文件保持原样；新版不加载旧版混淆脚本。默认头像复制自旧版，其余聊天界面使用可编辑的 CSS 和 React 组件。

## 运行

使用 Node.js 20.19+（建议 Node.js 22 LTS），在本目录执行：

```sh
npm ci
npm run dev
```

访问终端给出的本地地址（默认 http://127.0.0.1:5173）。当前机器默认 Node.js 16 无法运行新版，需要切换到上述版本。也可以使用本机 Codex 提供的 Node.js：

```sh
export PATH=/Users/flutter/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:$PATH
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5173
```

## 已实现

- 角色：添加、名称编辑、头像上传、删除、设置自己；自己消息显示在右侧。
- 删除有消息的角色会先确认，并一起移除其消息；至少保留一个角色。
- 消息：文字、多行、图片，编辑、删除、上下排序。
- 实时预览：圆形头像、浅灰背景、绿色气泡、在线状态、底部输入栏。
- 设置：对话标题、手机时间、电量、在线状态、画面宽度、最小高度。
- PNG 导出：3 倍分辨率，仅导出聊天画面；消息超出最小高度时自动延长。
- 草稿：自动保存在当前浏览器的 localStorage，刷新可恢复；读取失败回退到示例。

图片支持 PNG/JPEG/WebP/GIF，每张最大 8 MB；GIF 导出为静态图片。图片保存在浏览器本地，不上传服务器。浏览器存储配额有限，图片过多时会明确提示草稿保存失败；此时当前预览仍可导出。草稿不跨浏览器、域名或端口同步，也不自动读取旧版数据。

## 修改位置

| 文件 | 用途 |
| --- | --- |
| `src/model.ts` | 角色、消息、设置类型；默认数据；草稿读取；图片校验 |
| `src/App.tsx` | 编辑面板、状态更新、自动保存、图片导出 |
| `src/ChatPreview.tsx` | 聊天预览、头像、气泡、状态栏和输入栏 |
| `src/styles.css` | 编辑器样式、预览样式、响应式布局 |
| `public/media/` | 本地静态素材 |

新增消息类型时，扩展 `Message` 类型、编辑表单和预览渲染分支。调整气泡颜色、头像大小、字体和间距，修改 `styles.css` 的 `.bubble`、`.mine .bubble`、`.avatar` 和 `.chat-row`。

## 构建与部署

```sh
npm run build
npm run preview
npm run format:check
```

将 `dist/` 的内容上传到静态托管目录。Vite 使用相对资源路径，可放在子路径中，例如 `/editable/`。本地开发的 `/editable/` 是源代码目录，不能直接当作生产页面访问；需要先构建并部署 `dist/`。

本阶段未迁移红包、转账、语音、视频、完整机型库及旧版草稿导入。目标是先建立可维护的核心编辑流程；预览尽量沿用现有视觉，尚非逐像素复刻。
